# holdout-v1 — Veil 독립 평가셋

규칙을 고치는 데 쓰지 않은 문장으로 Veil의 탐지 성능을 재기 위한 평가셋입니다.
*A held-out set of 36 short documents (129 labeled entities) used only to measure detection, never to tune rules.*

## 다시 재는 법

```bash
node eval/holdout-v1/build.mjs                       # source.txt → docs/, gold.jsonl (이미 만들어져 있음)
node veil/scripts/eval.mjs eval/holdout-v1           # 정밀도·재현율
node veil/scripts/eval.mjs eval/holdout-v1 --show-errors
```

## 구성

| 구분 | 문서 | 내용 |
|---|---|---|
| 한국어 | 23 | 회의록, 상담 기록, 인사 메일, 메신저 대화, 계약 메모, 장애 보고, CSV·표·JSON·.env |
| 영어 | 9 | 이메일, 상담 티켓, 회의록, 인사 기록, 채팅, 설정 파일, 계약서 |
| 일본어·중국어 | 2 | 짧은 업무 메모 |
| 섞임·전각 | 2 | 한영 혼용, 전각 숫자로 쓴 전화·주민번호 |

이 중 7건은 개인정보가 없거나 거의 없는 문서(일상 대화, 상품 재고표, 패키지 설정 등)로, 오탐을 보기 위해 넣었습니다.

정답 표기 기준은 `source.txt` 맨 위에 있습니다. 요약하면 이름은 직함·조사를 뺀 이름만, 비밀값과 계좌는 값만(키 이름·은행명 제외), 날짜와 단독 도시명은 표기하지 않습니다.

## 이 숫자를 읽을 때 알아 둘 점

- **규모가 작습니다.** 개체 129개라 종류별 숫자는 몇 건 차이로 크게 흔들립니다. 특히 개수가 1~4개인 종류(PASSPORT, SSN, CARD, IP, ADDRESS)의 100%·0%는 참고만 하세요.
- **완전히 남이 만든 데이터는 아닙니다.** 규칙 코드와 같은 저장소에서, 같은 AI 도구(Claude)의 도움을 받아 작성했습니다. 규칙에 맞춰 문장을 고르지 않으려고 실제 업무 문서처럼 썼지만, 사람이 따로 모은 실제 데이터와 같다고 볼 수는 없습니다.
- **정답 표기를 한 번 고쳤습니다.** 첫 측정 뒤 표기 기준이 문서마다 달랐던 세 군데를 통일했습니다(비밀값의 키 이름, 계좌 앞 은행명, `株式会社`). 탐지 규칙은 이 평가셋을 보고 고치지 않았습니다.
- **이 평가셋의 틀린 사례로 규칙을 고치면** 그 순간 이 숫자는 더 이상 독립 평가가 아닙니다. 그때는 새 평가셋(holdout-v2)을 만들어야 합니다.

## 결과 (규칙만, `--ner` 없음)

측정: 2026-11-18, veil-skill 0.1.0 + 전각 문자 탐지

| | 정밀도 | 재현율 | F1 |
|---|---|---|---|
| strict (종류·위치 정확히 일치) | 88.1% | 69.0% | 77.4% |
| lenient (종류 같고 범위가 겹침) | 92.1% | 72.1% | 80.9% |

**가려짐(coverage) 재현율: 94/129 = 72.9%.** 종류와 상관없이 정답 글자가 모두 가려진 비율로, "개인정보가 실제로 AI에게 안 갔는가"에 가장 가까운 숫자입니다. 바꿔 말하면 **이 평가셋에서는 개인정보 약 4개 중 1개가 가려지지 않았습니다.** 전각 문자 처리를 넣기 전에는 92/129 = 71.3%였습니다.

### 드러난 약점

- **단서 없는 이름을 놓칩니다.** 메신저 대화의 발화자(`지수:`), 이메일 서명(`송지아 드림`), 직함 없는 영어 이름(`Marcus Lee`, `Eleanor Grant`), 호칭 없는 이름(`민수가`)이 대부분 빠졌습니다. 놓친 35건 중 26건이 이름입니다.
- **이름 일부만 가리는 경우가 있습니다.** `도현 님`에서 이름을 잡은 뒤 다른 곳의 `서도현`은 `도현`만 가려 성(`서`)이 남았습니다.
- **형식이 익숙하지 않은 식별번호를 놓칩니다.** `TCK-55120`, `EMP-30418`, 여권번호 `K04839215`.
- **일반 명사를 이름으로 잡습니다.** `고양이`, `손가락`, `기사`, `선생`, `인사팀`. 모두 "확인 필요"로 표시되지만 기본 동작에서는 가려집니다.
- **일본·중국 전화번호를 계좌로 분류합니다.** 가려지기는 하므로 유출은 아니지만 토큰 종류가 틀립니다.
- 형식이 정해진 정보(이메일, 카드, 주민번호, 비밀값, IP)는 이 평가셋에서 모두 잡았습니다.
